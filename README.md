# Talvoco UK wedding invitation template A3

Talvoco UK wedding invitation template A3 - demo with fictional names, dates and venues.

- Live demo: https://talvoco-wedding-a3.vercel.app/
- Built with Vite + React. Build and run locally: `npm install && npm run build && npm run preview` (or `npm run dev`)
- Contact values (RSVP WhatsApp number) are demo values in `src/data.js`: replace per customer.
- Crafted by [Talvoco](https://talvoco.com)
